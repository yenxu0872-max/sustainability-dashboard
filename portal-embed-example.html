Portal embed example

This is a stand-in for a school portal page. Below are the two ways to embed the dashboard.

1. Full dashboard (main content area)

Grows to fit its content when the portal allows the small script below; otherwise it scrolls inside a fixed height.

2. Summary widget (sidebar or home page)

Headline numbers and a one-line progress bar per project, with a link to the full dashboard.

Code to copy

Replace https://YOUR-DASHBOARD-ADDRESS/ with wherever the dashboard is hosted (it must be https).

<iframe class="sustainability-dashboard"
        src="https://YOUR-DASHBOARD-ADDRESS/index.html?mode=embed"
        title="Sustainability Dashboard"
        style="width:100%;height:900px;border:0;display:block"
        loading="lazy"></iframe>

<!-- Optional: lets the iframe grow to fit. Skip it if the portal doesn't allow scripts. -->
<script>
window.addEventListener("message", function (e) {
  if (!e.data || e.data.type !== "sustainability-dashboard:height") return;
  document.querySelectorAll("iframe.sustainability-dashboard").forEach(function (f) {
    if (f.contentWindow === e.source) f.style.height = e.data.height + "px";
  });
});
</script>
